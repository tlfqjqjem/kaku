FUNCTIONAL SPEC · v0.1

かく(Kaku) 기능 명세서 — 배포 전 개발 범위

2026-08-11 · 기획서 v0.1의 Phase 1을 구체화 · 결정사항 4건 반영(대시보드형 홈 / 목표 기반 streak / 레벨+시험일 온보딩 / 타이핑 우선 첫 경험)

0. 확정된 설계 원칙

  • 홈은 설정이 아니라 대시보드다. 열자마자 "오늘 할 일"이 보이고 버튼 하나로 시작한다.
  • streak은 '출석'이 아니라 '달성'이다. 일일 목표를 채워야 이어진다.
  • 첫 1분 안에 타이핑을 경험시킨다. 차별점을 첫 세션에서 만나게 한다.
  • 설정할 게 없는 앱. 온보딩 3스텝 이후에는 아무것도 설정하지 않아도 매일 굴러간다.

1. 화면 구조 (IA)

첫 방문→온보딩 S0→첫 세션(타이핑)→홈 S1
재방문→홈 S1 (대시보드)→오늘의 학습 S2 / 오답노트 S3 / 자유학습 S4 / 통계 S5 / 설정 S6
ID화면비고
S0온보딩첫 방문 1회만. 기존 사용자(기록 있음)는 건너뛰고 설정 유도 배너
S1홈 (대시보드)★ 신규 — 매일의 진입점
S2오늘의 학습 세션★ 신규 — 복습+새 단어 자동 구성 (스마트 세션)
S3오답 노트기존 유지
S4자유 학습기존 홈(레벨·덱·모드·문항 수 선택)이 이 화면으로 이동
S5통계★ 신규 — North Star 시각화
S6설정★ 신규 — 목표·시험일·발음·백업·초기화 모음

2. 화면별 스펙

S0온보딩 (4스텝 + 첫 세션)

  1. 컨셉 1장 — "보고 넘기면 잊습니다. かく는 직접 써서 외웁니다." + 타이핑 미리보기 애니메이션(mizu → みず). 버튼: [시작하기]
  2. 학습 목적 (세그먼트 질문) — "일본어, 왜 공부하세요?" 5택1: 💼 취업·이직 / 📝 JLPT 점수 필요 / ✈️ 유학·워홀 / 🎮 취미·덕질 / 🧳 여행. 단일 선택, 건너뛰기 가능. 익명 세그먼트 축으로 애널리틱스에 사용 (목적 × 레벨 × 시험일 유무)
  3. 목표 레벨 — N5~N1 선택 (기본 N3)
  4. 시험일 (선택) — 날짜 입력 → D-day 계산. [건너뛰기] 가능. 일일 목표는 기본 10문항으로 자동 설정(설정에서 변경 안내 한 줄)
  5. 첫 세션 — 선택 레벨의 빈도 상위 쉬운 단어 5문항, 타이핑(단어→읽기) 고정. 순수 맛보기: SRS·일일 집계·오답 노트에 기록하지 않음 (홈에 0/10으로 시작, 같은 단어를 오늘의 학습에서 다시 만남). 완료 화면은 점수만 — 틀린 단어 목록·목표 진행·진도 줄 없이 [홈으로] 버튼 하나 (v0.1 사용 피드백 반영, 2026-08-11)
이탈 방지 원칙: 온보딩에서 텍스트 입력은 시험일 하나뿐, 그마저 건너뛰기 가능. 가입·이름·이메일 없음.

S1홈 — 대시보드

🔥 12일째  ·  N3까지 D-87
오늘 목표 7 / 10 ▓▓▓▓▓▓▓░░░
📥 복습 만기 23 · 🆕 새 단어 대기 6 · 📕 오답 노트 9
오늘의 학습 시작 →
📕 오답 노트
자유 학습
📊 통계 · ⚙️ 설정
  • 목표 달성 시: 진행바 초록 + "오늘 목표 달성! 🔥 streak 이어짐" — 추가 학습은 계속 가능
  • 시험일 없으면 D-day 숨김. 시험일이 지나면 "시험 끝! 결과가 어땠든 단어는 남았어요 → 새 목표 설정" 배너
  • 복습 만기 0 + 새 단어 0이면: "오늘 복습은 없어요. 자유 학습으로 앞서 나가기" 안내

S2오늘의 학습 — 스마트 세션

  • 구성 로직(우선순위): ① SRS 만기 복습 → ② 오답노트(상자 낮은 순) → ③ 새 단어 순으로 목표 문항 수만큼 채움 — 기존 buildSession의 due→new 로직 확장
  • 범위: 온보딩에서 정한 목표 레벨. 덱은 대시보드의 단어/한자 토글로 선택 — 마지막 선택을 기억하며 기본은 단어 (매일 묻지 않음 = 마찰 최소화). 다른 레벨은 자유 학습에서
  • 출제 방식: 기존 mix 로직 그대로 (상자 0~1 고르기 → 2부터 타이핑)
  • 세션 완료 화면에 오늘 진행도(7/10)와 "한 세션 더" 버튼

S5통계

  • 정착 단어 누적 (상자4 이상 도달 수) — North Star. 큰 숫자 하나
  • 최근 7일 학습량 — 일별 문항 수 막대 + 목표선
  • 주간 정착 수 — 이번 주 상자4 도달 단어 수
  • 레벨별 진도(기존 막대), 오답 노트 현황

S6설정

  • 목표 레벨 / 시험일 / 일일 목표(10·20·30·50·직접)
  • 발음 자동 재생 on/off
  • 데이터 내보내기(JSON 파일 다운로드) / 가져오기(파일 업로드 → 병합 or 교체 선택)
  • 기록 초기화(기존 기능 이동)

3. 규칙 정의 (판정 로직)

규칙정의
일일 목표단위 = 채점된 문항 수(정답·오답 무관, 덱·모드 무관). 기본 10. 자정(기기 로컬 시간) 기준으로 리셋
streak 증가오늘 문항 수 ≥ 오늘의 목표값 → 그날 '달성'. 달성한 날이 이어진 일수가 streak
streak 끊김달성 못 한 날이 하루라도 지나면 0부터. (앱을 열었는지는 무관 — '달성'만 본다)
목표 변경 시판정은 항상 그날의 목표값 기준. 소급 재계산 없음
자정 걸친 세션문항이 채점된 시점의 날짜로 집계
정착(North Star)단어가 상자4에 처음 도달한 날 +1. 이후 떨어졌다 재도달해도 중복 집계 안 함
D-day시험일 − 오늘 (당일 = D-0). 지난 뒤에는 배너로 재설정 유도

4. 데이터 스키마 변경

localStorage kaku.v2에 추가 (기존 progress·custom·settings는 그대로 유지 = 기존 사용자 기록 보존):

필드내용
settings.targetLevel온보딩에서 정한 목표 레벨 (기존 level과 통합)
settings.examDate'2026-12-06' 형식, 없으면 null
settings.purpose학습 목적 세그먼트: job / exam / abroad / hobby / travel / null(건너뜀)
settings.todayDeck오늘의 학습 덱: word / kanji (대시보드 토글, 마지막 선택 기억)
settings.dailyGoal일일 목표 문항 수 (기본 10)
stats.daily{'2026-08-11': {n: 문항수, c: 정답수, s: 신규정착수}} — 날짜별 집계
stats.streak / lastMet현재 streak, 마지막 달성일 (매 채점 시 갱신)
stats.settledIds상자4에 도달한 적 있는 id 집합 (정착 중복 집계 방지)
onboarded온보딩 완료 여부. 기존 사용자(progress 있음)는 true로 마이그레이션

5. 예외 상황 (엣지 케이스)

  • 기존 사용자 첫 로드 → 온보딩 건너뜀, stats는 오늘부터 집계 시작, 홈에 "목표·시험일을 설정해 보세요" 배너 1회
  • 목표 레벨의 새 단어를 다 소진 → "N3 단어를 전부 만났어요!" + 다음 레벨 제안
  • 가져오기 파일이 손상/형식 오류 → 기존 데이터 유지, 오류 안내 (덮어쓰기 전 검증)
  • 같은 날 목표를 여러 번 바꿈 → 마지막 값 기준으로 그날 판정

6. 이번에 안 만드는 것 (스코프 아웃)

  • 푸시 알림 — 서버 필요, Phase 3
  • 계정·기기 간 동기화 — 내보내기/가져오기로 대체, Phase 3
  • 단어 뜻 신고 버튼 — 테스터에게는 구두/메모로 수집, 반응 보고 결정
  • 한자 덱의 오늘의 학습 편입 — v0.1 사용 피드백으로 스코프 인: 대시보드 단어/한자 토글로 반영 (2026-08-11)
  • 스코프 인 (타 앱 벤치마킹, 2026-08-11): 한자 상세 보기 — 단어 채점 후 "이 단어의 한자 N자" 버튼으로 구성 한자의 훈음·음독·훈독·예시를 펼쳐봄. 채점 전에는 숨김 (음독이 정답을 누설하므로 — 회독 앱과 달리 문제 풀이 앱이라 노출 시점을 늦춤)
  • 커뮤니티 피드백 (2026-08-11): 글자 수 힌트 → 박(拍) 수로 교체 — "根拠(こんきょ)를 4글자로 표기하면 3박 단어를 4박으로 오해할 수 있다"는 제보. 요음(ゃゅょ)=0박, 촉음(っ)·ん·ー=1박 규칙으로 박 수를 계산해 표시 (JLPT 청해의 박자 감각과 일치)
  • v0.1 사용 피드백 (2026-08-14): 대시보드 현황 줄 → 숫자 카드 4칸 — "N1·목표·복습·새 단어·오답"이 텍스트 한 줄에 몰려 줄바꿈되던 것을 오늘 목표/복습 만기/새 단어/오답 4칸 스탯 카드로 재배치, 목표 레벨 배지는 상단 streak 줄로 이동
  • 스코프 인 (2026-08-14): 일일 방문 기기 이벤트 (DAU) — 기존 방문 이벤트는 "연 횟수"라 중복 포함 → 기기가 하루 1회만 visit_daily를 전송해 중복 없는 일일 방문 기기 수(DAU 근사)를 확보. 방문 횟수 ÷ DAU = 1기기당 하루 평균 실행 횟수도 산출 가능. 한계: 폰+PC는 2로 집계, 데이터 삭제 시 신규로 집계
  • 스코프 인 (2026-08-14): D1/D7/D30 리텐션 이벤트 — 서버 없이 각 기기가 첫 사용일(localStorage)로부터 "정확히 1·7·30일째 재방문"을 스스로 판정해 return_d1/d7/d30을 1회씩 전송. 온보딩 완료 수를 분모로 리텐션 % 산출 (세그먼트 자동 부착 → "시험일 등록 유저의 D7" 비교 가능). 주차별 코호트 표는 여전히 Phase 3(자체 서버) 영역
  • v0.1 사용 피드백 (2026-08-13): 길이 힌트 제거 + 한자 상세 버튼 문구 개선 — ① 타이핑 문제의 박 수 힌트를 완전 제거 (정답 길이를 미리 알려줘 회상 난이도를 낮추던 요소 — 순수 회상 훈련으로 전환) ② 채점 후 한자 버튼을 ⭐ 이 단어의 한자 상세 뜻으로 변경 (글자 수 표기보다 "무엇을 볼 수 있는지"가 드러나는 문구)
  • v0.1 사용 피드백 (2026-08-11): 오늘의 학습 출제 방식 개편 — "새 단어가 전부 고르기로 나온다" 제보. ① 실력 맞춤 규칙을 상자0 1회만 고르기 → 상자1부터 타이핑으로 조정 ("쓰는 암기"가 기본이 되도록) ② 설정에 오늘의 학습 출제 방식(실력 맞춤/타이핑 위주/고르기 위주) 추가 — 회독 선호 사용자도 존중, 선택 비율은 today_mode_* 이벤트로 측정(가설 H1 보조 데이터)

7. 구현 순서

  1. stats 스키마 + 채점 시 일일 집계 기록 (모든 기능의 토대)
  2. S2 오늘의 학습(스마트 세션) + S1 대시보드 홈
  3. streak·D-day 판정 + 표시
  4. S0 온보딩 (+기존 사용자 마이그레이션)
  5. S5 통계 화면
  6. S6 설정 + 내보내기/가져오기

이후 → Phase 1b 배포 작업(모바일 점검·PWA·GitHub Pages·애널리틱스)으로 진행.
