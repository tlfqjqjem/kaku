# かく (Kaku) — 써보는 JLPT 단어장

일본어 단어를 **눈으로 회독하는 게 아니라, 직접 타이핑해서 인출하며 외우는** JLPT 단어·한자 학습 앱.

- 🖊️ 로마자 입력 → 히라가나 실시간 변환 (mizu → みず)
- 📚 JLPT N5~N1 단어 8,110개 · 한자 2,212자 (한국어 뜻·훈음)
- 🔁 SRS(라이트너 5상자) 복습 + 오답 노트 자동 수집·졸업
- 🔥 일일 목표·streak · 시험일 D-day
- 🔒 가입 없음 — 학습 기록은 기기(localStorage)에만 저장
- 📱 PWA — 홈 화면에 설치 가능
